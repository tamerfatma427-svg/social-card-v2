# Social Links Card (v2)

A social links profile card built with HTML and CSS. This is my own take on the [Frontend Mentor "Social links profile"](https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ) challenge, with a custom color palette, avatar, and styling.

## Built with

- Semantic HTML5
- CSS (Flexbox, hover and focus states, transitions)
- GitHub Pages for hosting

## Features

- Centered profile card with avatar, name, location, and short bio
- Five link buttons with a hover color change and a smooth transition
- Visible focus state for keyboard navigation
- Dark purple theme with an orange accent

## What I learned

- Centering and stacking elements with Flexbox
- Using `box-sizing: border-box` so widths and padding behave predictably
- Adding hover and focus states to interactive elements
- Deploying a static site with GitHub Pages
- Keeping file names consistent between the code and the repository
